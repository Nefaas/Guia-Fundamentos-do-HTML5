# 🌐 Guia Interativo: Fundamentos do HTML5

## 📚 Sobre o projeto

Este projeto apresenta um guia de aprendizado sobre os **fundamentos do HTML5**, desenvolvido para estudantes e pessoas que estão iniciando no desenvolvimento web.

O conteúdo aborda os principais conceitos necessários para compreender a estrutura de páginas HTML e utiliza exemplos práticos e exercícios interativos para facilitar o aprendizado.

Todo o material foi desenvolvido utilizando **Markdown** e organizado em módulos.

---

## 🎯 Objetivos

Ao finalizar este guia, você deverá ser capaz de:

* Entender o que é HTML5;
* Compreender a estrutura básica de um documento HTML;
* Utilizar tags e elementos HTML;
* Criar links e inserir imagens;
* Criar formulários básicos;
* Compreender HTML semântico;
* Identificar a função dos principais elementos HTML5.

## 📌 Conceitos principais

| Conceito       | Descrição                                                       |
| -------------- | --------------------------------------------------------------- |
| HTML5          | Linguagem de marcação utilizada para estruturar conteúdo na Web |
| Elemento       | Estrutura formada por tags e conteúdo                           |
| Tag            | Marca utilizada para definir elementos HTML                     |
| Atributo       | Informação adicional associada a um elemento                    |
| Formulário     | Estrutura utilizada para receber dados do usuário               |
| HTML semântico | Uso de elementos que representam o significado do conteúdo      |
