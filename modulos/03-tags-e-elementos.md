# 🏷️ 3. Tags e Elementos HTML

As páginas HTML são construídas utilizando elementos.

## Títulos

O HTML possui seis níveis de títulos:

```html
<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Outro título</h3>
```

O `<h1>` representa o nível mais alto e `<h6>` o nível mais baixo.

---

## Parágrafos

Para criar parágrafos utilizamos:

```html
<p>Este é um parágrafo.</p>
```

---

## Links

Links são criados utilizando `<a>`:

```html
<a href="https://example.com">Visitar site</a>
```

O atributo `href` define o destino do link.

---

## Imagens

Para inserir imagens utilizamos:

```html
<img src="imagem.jpg" alt="Descrição da imagem">
```

O atributo `src` indica o caminho da imagem.

O atributo `alt` fornece uma descrição alternativa.

---

## Listas

### Lista não ordenada

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

### Lista ordenada

```html
<ol>
    <li>Primeiro</li>
    <li>Segundo</li>
    <li>Terceiro</li>
</ol>
```
