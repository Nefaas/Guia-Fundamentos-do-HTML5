# 🌐 1. Introdução ao HTML5

## O que é HTML?

HTML significa **HyperText Markup Language**, ou Linguagem de Marcação de HiperTexto.

Ele é utilizado para estruturar o conteúdo de páginas web.

O HTML não é considerado uma linguagem de programação. Ele é uma **linguagem de marcação**.

---

## O que é HTML5?

HTML5 é uma versão moderna do HTML que trouxe novos elementos e recursos para a criação de páginas web.

Entre seus recursos estão elementos semânticos, formulários aprimorados, áudio, vídeo e outros recursos voltados para a Web.

---

## HTML x CSS x JavaScript

No desenvolvimento web, cada tecnologia possui uma função diferente:

| Tecnologia | Função                         |
| ---------- | ------------------------------ |
| HTML       | Estrutura e conteúdo           |
| CSS        | Aparência e apresentação       |
| JavaScript | Comportamento e interatividade |

Podemos imaginar uma página como uma casa:

* HTML → estrutura da casa;
* CSS → decoração;
* JavaScript → funcionamento e interações.

---

## 🧩 Exemplo

```html
<h1>Olá, mundo!</h1>
<p>Minha primeira página HTML.</p>
```

Nesse exemplo:

* `<h1>` representa um título;
* `<p>` representa um parágrafo.
